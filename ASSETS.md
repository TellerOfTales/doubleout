# ASSETS.md — the asset ledger

**Every visual and audio asset in DOUBLE OUT is produced by deterministic generator code
committed to this repository.** Nothing is downloaded, nothing is drawn by hand, nothing is
produced by an image or audio model, and no asset file of any kind ships with the game.

This satisfies TDD constraints C3 (zero cost), C4 (autonomously sourced art) and C5 (no
third-party intellectual property). The test in TDD §11.7 — delete `assets/generated/` and
rebuild — passes trivially, because **the game never reads those files at all**: the runtime
calls the same generators in memory at boot (`src/art/sprites.ts`). The PNGs exist so a
human can inspect the art and so the byte-identical rebuild can be verified.

## Fonts

Two bitmap faces, **defined in source code as arrays of row bitmasks** — no font file is
downloaded, bundled or referenced, so no font licence can attach:

- `src/art/glyphs5x7.ts` — the body face, 127 glyphs.
- `src/art/glyphs9x12.ts` — the headline face for the score and the 180 flash, 127 glyphs.

Coverage in both: ASCII 32–126, the Latin-1 set needed for French, German, Spanish, Italian
and Dutch (`à â ä ç è é ê ë î ï ô ö ù û ü ÿ á í ó ú ñ ¿ ¡ ß`), and `← → ↑ ↓ • · × …`.
Inspect them with `node --experimental-strip-types tools/fontpreview.ts 5x7|9x12`.

## Audio

No audio files. Every sound is synthesised at runtime by the Web Audio API from parameter
objects committed as source (`src/audio/defs.ts`), played by `src/audio/sfx.ts`. The
commentator voices are procedural blips (`src/audio/voice.ts`): square wave at 420 Hz for
BARREL, triangle at 180 Hz for NOCK.

## Third-party content

**None.** No external assets are used, so the TDD §11.7 exception process (CC0 only,
recoloured, original committed alongside) was never invoked and `assets/generated/` contains
no imported material.

No real people, organisations, tournaments, venues, broadcasters, sponsors or brands appear
anywhere in the build; the commentators BARREL and NOCK are invented, and `tests/barks.test.ts`
scans the bark pool for real proper nouns and for gambling terminology on every run.

## Code dependencies

Runtime: **zero**. Build only: vite (MIT), typescript (Apache-2.0), vitest (MIT),
pngjs (MIT), @types/node and @types/pngjs (MIT). `tests/architecture.test.ts` walks
`node_modules` and fails the build on any licence outside
MIT / BSD / Apache-2.0 / ISC / 0BSD / Zlib / CC0.
