# DOUBLE OUT

A single-player darts roguelite. Work a score down from 301, then 501, to exactly zero,
finishing on a double, in a shrinking number of visits. You aim wherever you like, every dart,
all night — a single at the number you called lands 97 times in a hundred, a treble lands 45,
and everything interesting lives in that gap. Beside the score is the slate, where contracts
are chalked up at printed prices. Eight legs make a night. A night can be won, and when it is,
the game stops.

**The visit.** Three darts. Before the first one, three contracts go up on the slate: take any
of them and you stake Pot against a printed price. They pull in different directions on
purpose — A TON wants the trebles, NO SCRAPS wants nothing under fifteen, THE QUIET wants a
visit under twenty-five, IN A BED wants all three darts in one number — so where to aim stops
answering itself. Then you point at the board and throw, and the fan of dots round the sights
is every place that dart could actually finish.

**The press.** A contract pays the instant it lands, straight into the Pot, where nothing can
reach it. Then you decide what to do with the money. **PRESS** puts double the stake back up on
something harder, using whatever darts are left. **PULL** gets you out of one that has not
landed, for half the stake back. A **BUST**, or a dart that finishes off the board, takes
everything still being chased — which is why the third dart at the trebles is a decision and
not a formality.

**The build.** Chalk bends the rules for the rest of the night, in a four-stage resolution
pipeline that can be chained until the arithmetic stops making sense. The kit holds one-shot
interventions — a steadier hand, a second throw, a dart that cannot go in the wall — spent on
a throw you have already chosen. Neither ever tells you where to aim. And the publican will
always sell you one more visit in the next leg, at a price that goes up every time you ask.

- **2D pixel art only**, 320×180 internal resolution, integer scaling, sixteen colours.
- **Every asset is generated by code** at build time — no downloaded art, no fonts, no audio
  files, no image models. Delete `assets/generated/`, rebuild, and nothing changes.
- **Zero runtime dependencies**, offline, no accounts, no telemetry, no purchases.
- Two commentators, BARREL and NOCK, with procedural blip voices.

## Play

```
npm install
npm run dev        # Vite dev server
npm run build      # genart → typecheck → bundle → dist/doubleout.html (single file, works offline)
npm test           # engine, determinism, bust table, aim, slate, acceptance, audio, barks, balance
npm run balance    # the §15 balance simulation (add :pairs for the 276-combination sweep)
npm run genart     # regenerate assets/generated/*.png + manifest
npm run screenshots    # drive the built game in Chromium and capture every screen
npm run decisions  # measure whether the loop actually contains decisions (docs/decisions/design.md)
```

Open `dist/doubleout.html` directly from disk — it needs no server.

**Controls.** Tap or drag on the board to aim; tap the called target again, or press **THROW**,
to let it go. The verbs on each contract are buttons. Keyboard: `←/→` step round the beds,
`↑/↓` move through the rings (bull, treble, single, double), `Enter`/`Space` throws, `1–4`
work the slate, `W` walks away from the visit, `K` arms the first thing in the kit, `H`
toggles the outcome fan and the checkout route, `Esc` pauses.

New to darts? The **TUTORIAL** on the menu is a real, playable leg that teaches the rules by
having you throw them — free aim, the gap between a safe single and a treble, taking a
contract, the press, what a bust costs you, the double finish and the shop — in about four
minutes.

## Layout

```
src/core      rules engine — headless, no imports from ui/art/audio
src/content   chalk, interventions, legs, oches, barks
src/art       palette, bitmap fonts (bit arrays), procedural generators, runtime atlas
src/audio     Web Audio synthesis (sfx, crowd, blip voices)
src/ui        canvas, renderer, input, screens (title, game, shop, results, settings, tutorial)
tools         genart, artpreview, fontpreview, balance, screenshot (Playwright), singlefile
tests         vitest suites
docs          the TDD, agent brief, per-area decision notes
```

See `DECISIONS.md` for every choice the TDD left open, and `ASSETS.md` for the asset ledger.
