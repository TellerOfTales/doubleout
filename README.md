# DOUBLE OUT

A single-player darts roguelite. Every dart has a chance of landing and a chance of drifting. Work a score down from 301, then 501, to exactly zero, finishing on a
double, in a shrinking number of visits — except you never aim. Throws are dealt from a deck
you build, and the board is progressively corrupted by chalk until the arithmetic stops
making sense. Eight legs make a night. A night can be won, and when it is, the game stops.

**The turn.** A visit is three darts and you are dealt **five cards** to spend on them, so the
big number you throw now is not there for the third dart. Every card shows what it would
*leave* you — brass for a finish, green for a position you can close, claret for a dead end.
**KEEP** banks one card in your pocket; it comes back every visit until you throw it, which is
how you have the right double ready for the 32 you meant to leave. **MISS** throws at the wall
on purpose: no score, no bust, but the visit ends there.

**The gamble.** Every visit you end without busting fills the crowd gauge, and a full gauge
pays the leg **double**. One bust empties it. Playing safe leaves Pot on the table; going for
the big score risks the lot.

- **2D pixel art only**, 320×180 internal resolution, integer scaling, sixteen colours.
- **Every asset is generated by code** at build time — no downloaded art, no fonts, no audio
  files, no image models. Delete `assets/generated/`, rebuild, and nothing changes.
- **Zero runtime dependencies**, offline, no accounts, no telemetry, no purchases.
- Two commentators, BARREL and NOCK, with procedural blip voices.

## Play

```
npm install
npm run dev        # Vite dev server
npm run build      # genart → typecheck → bundle → dist/doubleout.html (single file, works offline)
npm test           # 506 tests: engine, determinism, bust table, audio, barks, balance
npm run balance    # the §15 balance simulation (add :pairs for the 276-combination sweep)
npm run genart     # regenerate assets/generated/*.png + manifest
npm run screenshots    # drive the built game in Chromium and capture every screen
```

Open `dist/doubleout.html` directly from disk — it needs no server.

**Controls.** Flick a card upward at the board to throw it (touch or mouse). Tap a card to
select, tap again to throw. Keyboard: `1–4` pick a card, `←/→` move, `Enter`/`Space` throw,
`P` keeps the selected card in your pocket, `M` misses on purpose, `H` toggles the checkout
hint, `Esc` pauses.

New to darts? The **TUTORIAL** on the menu is a real, playable leg that teaches the rules by
having you throw them — dealt cards, the double finish, busting, the miss, the shop and a
chalk chain — in about three minutes.

## Layout

```
src/core      rules engine — headless, no imports from ui/art/audio
src/content   cards, chalk, legs, oches, barks
src/art       palette, bitmap fonts (bit arrays), procedural generators, runtime atlas
src/audio     Web Audio synthesis (sfx, crowd, blip voices)
src/ui        canvas, renderer, input, screens (title, game, shop, results, settings, tutorial)
tools         genart, artpreview, fontpreview, balance, screenshot (Playwright), singlefile
tests         vitest suites
docs          the TDD, agent brief, per-area decision notes
```

See `DECISIONS.md` for every choice the TDD left open, and `ASSETS.md` for the asset ledger.
